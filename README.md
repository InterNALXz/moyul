# VSCode 风格跨端口通信（单网页双角色）

## 功能概览

- 单个网页同时支持主动建联与被动接收（弹窗接受/拒绝）。
- 支持多会话并行通信，一个页面可同时与多个对端通信。
- 中间区域按“文件行”展示会话内容，底部 `NEW` 行可直接输入并回车发送。
- 普通显示为替换后的文本（如有替换来源），鼠标悬浮才显示原始会话内容。
- 左下角配置菜单支持默认替换文件夹、Relay 服务器等二级设置项。

## Relay 用户名与加密机制

本版本新增以下能力：

- 连接 Relay 时必须注册用户名（`2~32` 位，支持中文、`a-zA-Z0-9._-`）。
- Relay 内部以 `peerId` 维护连接索引，并支持用户名路由。
- 发送数据消息时，发送端用自己的 `ID` 做异或加密。
- Relay 收到后用发送端 `ID` 解密，再用接收端 `ID` 重新加密转发。
- 接收端收到后用自己的 `ID` 解密。
- 建联时支持直接填用户名（如 `@alice` / `alice` / `@张三`）进行建联。
- Relay 提供用户名解析接口，建联时会优先按用户名解析到 `peerId` 再投递，避免 400。

## 帮助面板

- 顶部菜单点击 `帮助` 可查看：
  - 当前用户名
  - 当前 ID（peerId）
  - 当前端点（ip:port）
- 提供“一键复制身份信息”按钮，便于快速分享给对端。

## 编码说明（避免乱码）

- 本项目所有文件统一使用 `UTF-8` 编码。
- 如果在编辑器里看到乱码，请在 VS Code 使用：
  - `Reopen with Encoding` -> `UTF-8`
  - 或 `Save with Encoding` -> `UTF-8`

### 1) 启动 Relay

```bash
node relay-server.js
```

默认监听：`http://127.0.0.1:9000`

自定义端口：

```powershell
# Windows
$env:RELAY_PORT = 9100
node relay-server.js
```

```bash
RELAY_PORT=9100 node relay-server.js
```

### 2) 启动两个网页端口（示例）

```bash
# 终端 A
python -m http.server 5500

# 终端 B
python -m http.server 5501
```

打开：

- `http://127.0.0.1:5500/index.html`
- `http://127.0.0.1:5501/index.html`

如果 Relay 不是 `9000`：

- `http://127.0.0.1:5500/index.html?relay=http://127.0.0.1:9100`
- `http://127.0.0.1:5501/index.html?relay=http://127.0.0.1:9100`

## 使用流程

1. 左下角配置 -> `Relay 服务器`：填写 Relay 地址与用户名，保存并重连。
2. 在资源管理器右上角 `+` 展开建联输入框。
3. 输入对端地址或用户名（如 `127.0.0.1:5501` / `@alice` / `@张三`），点击“发起建联”。
4. 对端弹窗点击“接受”后，双方可在中间文件区按行通信（回车发送）。
5. 悬浮某一行可查看该行原始文本（含 `W/R` 标记）。
